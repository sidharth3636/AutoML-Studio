# AutoML Studio


AutoML Studio is a Python-based desktop application that simplifies machine learning workflows using an interactive GUI.

It supports:
- Data preprocessing
- Label encoding
- Date feature engineering
- Missing value handling
- Outlier detection
- Regression & classification
- Bayesian hyperparameter optimization
- Multi-output ML models
- Automated training pipeline

---

## Features

### GUI Interface
- Built using CustomTkinter
- User-friendly dataset upload system
- Interactive workflow execution

### Data Preprocessing
- Label encoding for categorical data
- Date detection and feature engineering
- Missing value imputation
- Outlier handling using Isolation Forest
- Dataset normalization

### Machine Learning
Supports:
- Logistic Regression
- Linear Regression
- Ridge & Lasso
- Random Forest
- Extra Trees
- Gradient Boosting
- XGBoost

### Optimization
- Bayesian Hyperparameter Optimization using BayesSearchCV
